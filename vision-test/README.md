# בדיקת חדות ראייה

אתר בדיקת ראייה להדגמה בקובץ אחד (`index.html`), בלי תלויות, שרץ בטלפון ובמחשב.

- כיול גודל המסך לפי מטבע ₪1/₪5/₪10 או כרטיס אשראי (קנה מידה 1:1)
- בדיקה לפי מרחק (2/3/4 מטר) עם אותיות, ספרות או E, מסך מנחה ומקלדת
- כל עין בנפרד, שתי עיניים ובדיקה חוזרת דרך חור סיכה
- שאלון אופציונלי: כל שאלה אפשר לדלג עליה או לסמן "לא ידוע"
- סיכום על צורך אפשרי במשקפיים, ותמונת דוח לשמירה ושיתוף

הבדיקה להדגמה בלבד ואינה מחליפה בדיקה אצל אופטומטריסט.

הרצה: לפתוח את `index.html` בדפדפן.
